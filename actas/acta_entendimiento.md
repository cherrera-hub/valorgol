## 1. Objetivo común
Desarrollar una aplicación web interactiva con Streamlit, de cuatro páginas (Inicio, Explorar, Jugar y Mis datos), a partir de un conjunto de datos real de jugadores de fútbol con más de 1.000 registros, y entregarla en un repositorio de GitHub con toda su documentación.

## 2. Objetivos específicos
1. Seleccionar, limpiar y documentar el conjunto de datos en `limpieza.ipynb` y exportarlo a `data/datos.csv`.
2. Construir una aplicación con identidad visual propia: nombre, logo y paleta de colores.
3. Diseñar un juego original cuya mecánica dependa directamente de los datos de los jugadores.
4. Aplicar los conceptos del curso: funciones, condicionales, ciclos, listas, diccionarios, manejo de excepciones, Pandas y programación orientada a objetos básica.
5. Entregar la documentación completa: README, licencia, requisitos, cronograma, presupuesto, plan de versionado y manual de usuario.
6. Lograr que ambos integrantes comprendan y puedan explicar todo el código en la asesoría y la sustentación.
